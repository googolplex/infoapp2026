# Informática Aplicada 2026

Repositorio de referencia para la asignatura **Informática Aplicada**, impartida durante el año 2026 en la **Facultad Politécnica de la Universidad Nacional de Asunción (FP-UNA)**.

## Idioma del proyecto

El idioma de trabajo del repositorio es **español**.

- La planificación, las misiones, los materiales docentes, los informes y la documentación se redactarán en español.
- Los términos técnicos en inglés podrán conservarse cuando sean de uso habitual o cuando su traducción reduzca la precisión.
- Las fuentes bibliográficas en otros idiomas conservarán sus títulos originales.
- No se cambiará de idioma sin una necesidad académica explícita.

## Propósito

Este repositorio centraliza el material académico y técnico de la asignatura:

- planificación y programa;
- materiales de clase;
- ejercicios y prácticas;
- evaluaciones;
- recursos complementarios;
- proyecto final;
- instrucciones para asistentes de inteligencia artificial.

## Estado

Proyecto en preparación para el periodo académico 2026.

## Forma de trabajo

1. Cada tema de clase tendrá su propia carpeta o archivo.
2. Las prácticas deberán indicar objetivos, requisitos, instrucciones y criterios de entrega.
3. Las evaluaciones se mantendrán separadas del material público cuando contengan respuestas o información reservada.
4. Los cambios importantes deberán quedar documentados mediante commits descriptivos.
5. Las tareas para asistentes de IA se definirán como misiones concretas dentro de `misiones/`.
