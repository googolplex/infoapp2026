# Proyecto final

## Propósito

Definir una actividad integradora en la que los estudiantes apliquen los conocimientos desarrollados durante la asignatura.

## Elementos pendientes

- problema o dominio;
- alcance;
- modalidad individual o grupal;
- tecnologías permitidas;
- entregables;
- hitos;
- rúbrica;
- presentación o defensa;
- política de uso de IA.
