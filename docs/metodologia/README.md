# Metodología

La metodología general de la asignatura se denomina **construcción de clases**.

Documento de referencia actualmente ubicado en:

`docs/20260725a_Construccion_de_clases_Informatica_Aplicada_2026.pdf`

Toda planificación, actividad o material debe mencionar brevemente que el docente presenta un esqueleto, los estudiantes construyen la base de conocimientos y la matriz de información, el contenido se valida en clase, incorpora texto, gráficos y videos, y cada estudiante produce un resumen personal antes de finalizar.

Las nuevas versiones metodológicas pueden guardarse en esta carpeta, conservando la versión anterior y actualizando `docs/contexto/README.md`.
